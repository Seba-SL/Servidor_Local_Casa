<img src="html/img/icono.png" alt="Descripción de la imagen" width="80" > Servidor Local Ardilla

Desarrollo de un servidor local de uso hogareño, utilizando diferentes herramientas de codigo abierto como Homepage, Jellyfin, Samba, NetData, entre otros.

Objetivos :
Facil ,amigable e intuitivo de usar para todos los integrantes de una familia.
Compatibilidad con cualquier marca de dispositivo de IoT.

Implementación:
En netbook vieja, se le instalo debian 12, sin interfaz grafica, solo su terminal.

Almacenamiento:
Externo en discos HDD reciclados, escalamiento esperable en discos SSD.
